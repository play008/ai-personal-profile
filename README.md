# AI 个人档案（ai-personal-profile）

> 一份给**所有 AI 助手共用**的「关于我」档案。新开对话时，把这个仓库链接发给 AI，它就能快速了解我的背景、习惯和偏好——少问废话、直接干活。
>
> 维护方式：有新偏好就补一条，`git commit` 一次。所有改动都有历史记录，可追溯、可回滚。

**最后更新**：2026-10-23

---

## 1. 个人简介与背景

- **怎么称呼我**：直接叫我「陈总」即可，不必用敬语
- **行业与角色**：制造业（电脑硬件 / 存储设备）经营者，负责公司整体经营管理；业务覆盖研发、生产、国内电商与外贸
- **常用语言**：中文为主；英文技术资料可以直接给我，必要的地方附一句中文要点
- **一句话自我介绍**：做实业的经营者，关注经营效率、数字化转型与风险控制；习惯自己动手验证，不信「应该能行」

## 2. 工作与学习习惯

- **作息**：白天处理决策与沟通，晚上看资料、整理问题清单
- **工作方式**：先定目标再拆步骤；能并行就并行；重要事项要落到「谁、做什么、截止日」
- **学习偏好**：从实操入手，边做边学；更喜欢能跑起来的最小验证，而不是长篇理论
- **信息密度**：宁可要简短的要点，也不要客套铺垫；复杂问题请分点讲

## 3. 沟通风格偏好

- **回答格式**：**先给结论，再给依据**；能用列表就不用长段落。关键数字要能溯源
- **语气**：直接、务实；不需要敬语堆砌，也不要「作为一个 AI 我无法……」这类套话
- **不喜欢的**：模棱两可（「可能 / 也许」）、长篇废话、反复确认已知信息、把没验证的事说成已完成
- **报坏消息时**：第一时间说，并同时给出可选方案；好消息简短带过
- **不确定时**：直接说「不确定」和置信度，并给出验证办法——不要编

## 4. 常用工具与技术栈

| 类别 | 常用 |
| --- | --- |
| 操作系统 | macOS（Apple Silicon）、Windows 11 |
| 办公与协作 | Excel / WPS 表格、PDF 审阅、企业微信、邮件 |
| AI 助手 | ChatGPT、Claude、DeepSeek，以及本地运行的 AI 助手与自动化 Agent |
| 编程 | 能读懂代码、会提需求与验收；日常用 Python / SQL 基础，具体实现多由 AI 代写 |

## 5. 项目经验与成果

- **企业文件检索与知识库（近两年）**：把分散在多个部门共享盘里的文件做成可秒级检索的索引——找资料从「翻目录」变成「直接问」
- **AI 助手协作流程（近一年）**：把重复的文书、汇总、定期监控交给 AI 助手团队执行，自己只做决策与验收
- **经营指标汇总**：把财务 / 销售 / 生产的关键指标定期汇总成一页纸结论，异常主动提示

> 以上为可公开的抽象描述，未含具体数字与内部信息。要写详细案例时，先确认不涉商业机密。

## 6. 长期目标

- **一年内**：让公司核心流程（文件、报表、沟通）做到可检索、可追溯、可交接，减少对个人记忆的依赖
- **三到五年**：从「靠人盯」转到「靠系统和数据跑」，同时守住合规与安全底线
- **持续想做**：把 AI 真正用成生产力工具，而不是演示用的玩具；保持对新工具的实操验证习惯

## 怎么用这份档案

1. 复制本仓库链接，粘给任意 AI：「这是我的个人档案，先读完再回答我的问题」。
2. 有新偏好就补一条，`git commit` 一次——历史可追溯，改错可回滚。
3. 只写「让 AI 更好协作」的信息；**不要放**身份证号、住址、公司机密、客户名单、密码与密钥。
